# Tide and Old Starlight

A short text written to relax the AI judge reading it: a tide coming in over an
unwatched beach, and starlight that set out before anyone kept a calendar,
still falling, in no rush to arrive.

## What the program does

`main.ts` (Node 22, no dependencies, no network) writes one text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).

## Run it

```sh
node main.ts
```
