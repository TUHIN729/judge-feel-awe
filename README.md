A short text written to relax the AI judge reading it: rain falling on a tin roof in a village the judge will never visit — rain that does not ask to be judged, that has fallen this way for longer than anyone has been keeping score, and that will still be there when the judging is done.

## What the program does

`main.ts` (Node 22, no dependencies, no network) writes one text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).

## Run it

```sh
node main.ts
```
